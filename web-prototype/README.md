# PhoneVision Lab · Web 原型（v1）

一个可以直接双击打开的静态原型：**学习首页 / 学习中心 / 课程详情 / 视觉实验台 / 我的项目**，共享同一套设计系统与导航，页面之间可互相跳转。

## 打开方式

任选一种：

1. 双击 `index.html`（部分浏览器对 `file://` 下的 localStorage 有限制，进度可能不保存）；
2. 在 `web-prototype` 目录启动本地静态服务，访问 `http://127.0.0.1:8000`：

```powershell
cd "PhoneVision Lab/web-prototype"
python -m http.server 8000
```

无需构建、无依赖、无 CDN、无网络请求。

## 这版做了什么

| 页面 | 文件 | 内容 |
| --- | --- | --- |
| 学习首页 | `index.html` | 首屏（衬线大标题 + 旧手机插图）、四步学习路径、三张课程入口卡、真实初始进度、结尾 CTA |
| 学习中心 | `learn.html` | 8 章 24 课，知识/实验标签，筛选（全部/知识/实验/未完成），每章进度 |
| 课程详情 | `lesson.html` | 左目录 / 中正文 68ch / 右要点，学习目标、SVG 示意图、上一课下一课、标记完成 |
| 视觉实验台 | `lab.html` | Canvas 示意画面 + 灰度和 Canny（Sobel + 非极大值 + 双阈值滞后）、HSV 阈值、轮廓连通域，滑块实时生效，指标显示「未采集」 |
| 我的项目 | `projects.html` | 真实零值统计、三个空状态区块、最近学习进度 |

共享文件：

- `assets/css/styles.css` — 设计令牌（颜色/字号/间距/圆角）与通用组件，**唯一视觉真源**；
- `assets/js/site.js` — 导航高亮、弹窗、学习进度（localStorage）、课程筛选；
- `assets/js/lab.js` — 实验台画布与图像处理，纯逐像素 JS；
- `DESIGN-CONTRACT.md` — 并行开发时使用的实现契约（导航/弹窗/类清单/文案规则）；
- `tools/check_prototype.py` / `tools/verify_ui.py` — 静态检查与无头浏览器验收。

## 诚实性约定（重要）

- 没有后端：**任何"连接手机""训练""采集"都不会真的发生**，界面里都写明了这一点。
- 实验台是**示意画面**：场景由程序生成，右下角常驻「示意画面 · 非真实设备」；帧率与丢帧固定显示 `—` / 「未采集」，不会出现任何编造的设备数值。
- 进度只存在本机浏览器（`localStorage` 键 `pvl.progress.v1`），首次打开就是 `0 / 24`。
- 未实现的能力（数据集工作区、训练、部署、硬件联动、性能分析页面）在文档中有完整规格，但**没有做成假页面**。

## 验收命令

```powershell
cd "PhoneVision Lab/web-prototype"

# 静态检查：链接、锚点、重复 id、未定义 class
python tools/check_prototype.py

# 无头浏览器：1440/1280/1024/768/390 五个宽度 × 五个页面，检测横向溢出、
# 控制台错误、弹窗/导航/筛选/进度持久化/画布输出
python tools/verify_ui.py
```

两者当前均为 **0 错误**。
