01

第 1 章：认识视觉 AI

先建立词汇：像素、通道、分辨率，以及旧手机在整条链路里的位置。

本机进度 0 / 3

  1. 什么是计算机视觉知识 先分清相机、算法与判断三件事 未开始 →
  2. 图像是数字组成的知识 像素是数字，画面是排好队的表格 未开始 →
  3. 旧手机能做什么知识 算力有限，但采集与本地推理够用 未开始 →

前三课按顺序读，别跳

「图像是数字组成的」是后面所有处理与训练的地基。如果只想快点看到效果，可以先到实验台，但回来仍建议补上第 1 章。

02

第 2 章：使用手机采集图像

让手机与电脑在同一局域网里说上话，并决定传多大的画面。

本机进度 0 / 3

  1. 局域网推流是怎么工作的知识 手机出画面，电脑经局域网逐帧接收 未开始 →
  2. 连接你的旧手机实验 填地址、点连接，确认画面能稳定到达 未开始 →
  3. 分辨率与画面质量实验 改分辨率，观察清晰度与帧率的变化 未开始 →

03

第 3 章：体验图像处理

灰度、边缘、颜色与轮廓：四个最常用的传统视觉步骤。

本机进度 0 / 4

  1. 灰度：先去色再计算知识 去掉颜色，只留亮度，计算会更快 未开始 →
  2. Canny 边缘检测实验 用双阈值找出画面里的轮廓线 未开始 →
  3. HSV 颜色分割实验 按色调与饱和度筛出目标颜色区域 未开始 →
  4. 轮廓与面积过滤实验 去掉过小的噪点，只留下目标形状 未开始 →

04

第 4 章：创建分类数据集

把随手拍变成可训练的数据集，并做一次数据体检。

本机进度 0 / 3

  1. 分类数据集长什么样知识 每张图一个标签，目录就是类别 未开始 →
  2. 采集：单张与连续实验 单张补漏，连续采集快速攒样本 未开始 →
  3. 数据体检与训练/验证划分实验 先查重复与模糊，再按比例切分 未开始 →

05

第 5 章：训练模型

理解训练在调什么，再跑一次小规模实验。

本机进度 0 / 4

  1. 训练到底在做什么知识 不断调参数，让预测尽量贴近标签 未开始 →
  2. 参数怎么选知识 学习率、批大小与轮数各自影响什么 未开始 →
  3. 开始第一次训练实验 跑一次小规模训练，看损失是否下降 未开始 →
  4. 看懂准确率与过拟合知识 训练集好看，不代表新图片也认得出 未开始 →

训练前检查清单

  • 训练集与验证集已经分开，划分比例写清楚。
  • 每个类别的样本量大致接近，没有空类别。
  • 训练需要独立的 Python 环境（requirements-train.txt），便携包不内置 TensorFlow。
  • 网页原型不会真的训练模型；真实训练需要独立的 Python 环境。

以上任一项不满足，先回到第 4 章整理数据。

本机进度 0 / 3

  2. 导入并在手机本地推理实验 把模型放进 App，断网也能给出结果 未开始 →
  3. 预测不准怎么排查知识 从光线、构图与训练数据三条线找原因 未开始 →

07

第 7 章：硬件联动

从一根杜邦线开始，把分类结果变成 LED 的亮与灭。

本机进度 0 / 2

  1. ESP32 与 LED 接线知识 认清引脚与电平，别把电源接反 未开始 →
  2. 手动测试与自动联动实验 先手动点亮，再让规则接管 未开始 →

08

第 8 章：性能分析

分清三种帧率，采样并导出可核对的数据。

本机进度 0 / 2

  1. 三个帧率不是一回事知识 采集、传输与显示各有各的计数口径 未开始 →
  2. 采样并导出报告实验 记录一段真实传输，导出可核对的数据 未开始 →

报告包含什么

  • 采样时长、设备与分辨率
  • 接收帧率与显示帧率
  • 丢帧计数与时间戳
  • 原始采样记录（CSV）
  • 未采集：手机推理耗时、硬件执行耗时、功耗

学习建议

按章读，按课做，别急着训练

知识课先读一遍建立概念，实验课按课程说明动手。网页原型在实验台提供图像处理与采集的示意交互，数据集、训练与硬件步骤需要在桌面客户端完成。每课的完成标记只写入本机浏览器，不联网、不上传，也不代表真实设备已经验证。

通常，数据集质量比训练参数更影响结果。建议先完成第 1–3 章，再开始采集自己的数据。

局域网连接

连接你的旧手机

  1. 让两台设备连同一个 Wi-Fi。手机和电脑必须在同一局域网，不要用手机热点做桥接。
  2. 在手机 App 里点「开始推流」。App 会在屏幕上显示本机地址，例如 192.168.2.14:8080。
  3. 把地址填到下面。电脑会先请求 /ping 确认手机在线，再开始接收 MJPEG 画面。

常见问题

连不上手机？

确认手机 App 已点「开始推流」、两台设备在同一 Wi-Fi、地址与 App 显示一致。电脑上可先访问 http://手机IP:8080/ping 验证。

训练按钮是灰的？

训练需要独立的 Python 环境（requirements-train.txt）。便携包不内置 TensorFlow，请改用 start-training.cmd 启动。

为什么 LED 没有真的亮？

ESP32 与 LED 的真机链路仍在验证中。电脑端只能确认到「已接收」，没有「已执行」回执时不会显示成功。

数据存在哪里？

默认在本机 %LOCALAPPDATA%\PhoneVisionLab，不上传云端，也没有账号体系。
