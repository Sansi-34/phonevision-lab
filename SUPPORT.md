# Support

PhoneVision Lab is a small, learning-focused, MIT-licensed project. Support is
community-driven — there is no commercial support team.

> 中文问题同样欢迎：直接在 Issue 里用中文提问即可。

## Getting help

- **Questions, bugs, feature ideas**: open a GitHub **Issue** in this repository.
  Use the provided issue templates (bug report / feature request) so we can help
  you quickly.
- **Security issues**: do **not** open a public issue. Use the private
  vulnerability reporting path — see [SECURITY.md](SECURITY.md).
- **Before asking**, a quick search of existing issues may already have an answer.

## What to include in a support issue

To reproduce and diagnose efficiently, please include only:

- PhoneVision Lab version and how you run it (source `python main.py ...` or the
  Windows portable package)
- Platform (Windows / Android / other)
- What you did, what you expected, and what actually happened
- A **summary** of relevant log lines — not full logs (see privacy below)

## Privacy

Please **do not** include private information in issues:

- No screenshots showing real faces, personal surroundings, or identifiable content
- No real IPs / usernames / paths / serial numbers beyond what is needed
- No full log dumps or captured frames
- No secrets, tokens, or keys — if you think one leaked, report via the private
  security path instead

## Scope of support

- This is a learning project; we are happy to help you understand how it works.
- We cannot promise response times or fix timelines.
- Feature requests are welcome as issues, and are prioritized by maintainer
  availability — see [ROADMAP.md](ROADMAP.md).
